# Telecom Support Bot 🎧

Многофункциональный Telegram-бот техподдержки мобильного оператора, написанный на Python (aiogram 3) с использованием асинхронной базы данных (SQLAlchemy). 

Бот реализует полноценную систему ролей (Абонент, Оператор, Администратор) с возможностью живого общения в реальном времени и ИИ-ассистентом.

## 🌟 Основной функционал

**Для абонентов:**
- Личный кабинет с просмотром баланса и активного тарифа.
- Пополнение баланса (Telegram Payments) и заморозка счёта.
- Смена тарифов.
- Умная очередь ожидания и живой чат с оператором техподдержки.
- Оценка работы оператора (от 1 до 5 звезд) после завершения диалога.
- ИИ-помощник, знающий тарифы и FAQ (Gemini API).

**Для операторов:**
- Рабочая панель со статусами (На смене / Не в сети).
- Просмотр очереди ожидания и перехват клиентов.
- Карточка абонента при соединении (баланс, тариф, статус).
- Просмотр личной статистики (рейтинг, количество чатов, отзывы).

**Для администраторов:**
- Генерация одноразовых инвайт-кодов для регистрации новых сотрудников.
- Блокировка и разблокировка администраторов.
- Управление базой FAQ и тарифами.
- Просмотр статистики тарифов и отзывов на всех операторов.

## 🛠 Технологии
- **Python 3.11+**
- **aiogram 3.x** (Асинхронный фреймворк для Telegram API)
- **SQLAlchemy 2.0** + **aiosqlite/psycopg** (Асинхронная ORM)
- **PostgreSQL / SQLite** (База данных)
- **google-genai** (Интеграция нейросети)
